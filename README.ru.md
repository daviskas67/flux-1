# Флюкс-1 — 1-битный Тьюринг-шторм

Не просто 1 бит. Это **массово-параллельный однобитный процессор**: матрица
**16×16 = 256 вычислительных узлов**, по которым бегают волны битов, как муравьи.
Каждый узел — одновременно элемент памяти, крошечное АЛУ и маршрутизатор.

Поверх сетки — **3 квадратных звуковых канала (square wave)**, которые
намеренно **ничем не ограничены**: частоту, амплитуду, фазу и FM-маршрут
задают *сами волны*. При правильных параметрах — честный FM-синтез.
Сетка сама является секвенсером.

## Возможности

* **256 клеток** (16×16), у каждой — 1-битный регистр данных, постоянный
  1-битный аккумулятор и собственная мини-программа правил.
* **Программирование волнами**: вы пишете *карту потоков*, а не линейный код —
  «если твой бит = 1, передай его соседу на востоке через 2 такта».
* **3 квадратных канала с FM**: `chan 2 square freq 220 amp 0.6 mod 0 400`.
  Волны могут переписывать любой параметр канала в любой такт — секвенсоры,
  LFO, вибрато и полноценные FM-кларнеты рождаются прямо из сетки.
* **Синхронные двухфазные такты** (вычисление → фиксация), как в настоящей
  цифровой логике.
* **Экспорт WAV** (`--wav out.wav`) — моно, 16 бит, звук рендерится синхронно
  с сеткой.

## Сборка и запуск

Нужен компилятор C++17 (g++ / clang++ / MSVC).

```bash
g++ -O2 -std=c++17 main.cpp flux1.cpp -o flux1

# анимация змейки
./flux1 examples/serpent.flux

# шторм со следами-аккумуляторами, один финальный кадр
./flux1 examples/storm.flux --acc --quiet

# FM-синтез сразу в файл
./flux1 examples/fm.flux --wav fm.wav

# чип-арпеджио из трёх рядов волн
./flux1 examples/arp.flux --wav arp.wav
```

### Опции CLI

```
flux1 program.flux [--acc] [--ticks N] [--steps N] [--pause MS] [--quiet] [--wav out.wav]
```

| Опция         | Назначение                                        |
|---------------|---------------------------------------------------|
| `--acc`       | рисовать аккумуляторы как `A`                     |
| `--ticks N`   | перекрыть число тактов                            |
| `--steps N`   | печатать каждый N-й кадр при анимации             |
| `--pause MS`  | перекрыть задержку кадров                         |
| `--quiet`     | без анимации; только финальный кадр               |
| `--wav FILE`  | записать звук (WAV, моно, 16 бит)                 |

## Язык за 60 секунд

```flux
steps 200                       # сколько тактов симулировать
cell 0 0 : always emit E 1      # генератор: постоянно излучает 1 на восток
rule bit1 send E 2              # всюду: передавать биты на восток, прыжок 2 такта
rule bit1 toggleacc             # каждый прыжок оставляет след-аккумулятор
chan 2 square freq 220 amp 0.6 mod 0 400   # FM-кларнет
```

Полный справочник: [docs/LANGUAGE.ru.md](docs/LANGUAGE.ru.md)

## Модель за 30 секунд

* Каждый такт — две фазы: **A — вычисление** каждой клетки, **B — фиксация**
  всех перемещений одновременно. Аккумуляторы переживают такты.
* Волна с `send DIR D` приземляется у соседа через `D` тактов и становится
  действующей ещё через один (`delay 0`).
* Коллизии: побеждает первая волна (работает как примитив слияние/поглощение).
* Звук: каждый такт сетки рендерит `sps` сэмплов (по умолчанию ≈735,
  ~60 тактов/сек).

Полная модель: [docs/ARCHITECTURE.ru.md](docs/ARCHITECTURE.ru.md)

## Примеры

| Файл                | Что показывает                                      |
|---------------------|-----------------------------------------------------|
| `pulse.flux`        | поезд волн: генератор гонит 1-биты на восток        |
| `wave.flux`         | одна волна огибает периметр матрицы                 |
| `serpent.flux`      | бит рисует змейку по всей сетке                     |
| `storm.flux`        | три волны, каждая оставляет след-аккумулятор        |
| `logic.flux`        | два потока сходятся в И-гейт (acc=1, когда пришли оба)|
| `fm.flux`           | FM-синтез: несущая 220 Гц модулируется LFO, частота секвенсится волнами |
| `arp.flux`          | чип-арпеджио: 3 ряда волн играют ноты на 3 каналах  |
